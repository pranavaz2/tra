## Version Policy

- **Python** — always `3.12.x`. The `.python-version` file in `apps/api/` is authoritative.
- **Flutter** — always the latest stable channel release.
- **Pinned versions** — `pyproject.toml` specifies minimum versions, not exact pins.
  The lockfile (generated by the package manager) pins exact versions for reproducible builds.
- **PostgreSQL** — `16.x`. The PostGIS Docker image tag (`16-3.4`) pins the major version.
- **Redis** — `7.x`. The Docker image tag (`redis:7-alpine`) pins the major version.

## Upgrade Policy

- Dependency upgrades are PRs against `main`, reviewed by at least one engineer.
- Major version upgrades require an ADR if they affect the public interface of the technology
  (e.g., SQLAlchemy 2 → 3, FastAPI 0.x → 1.x, Pydantic v2 → v3).
- Security patches are applied immediately and bypass the normal PR review timeline.
